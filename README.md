# Лист персонажа AZAG

Редактируемый лист персонажа для игры **AZAG (Dank Dungeons)** — расширение для
[Owlbear Rodeo](https://owlbear.rodeo). Сделан по PDF-бланку «Лист AZAG А4»:
фон — отрисованная страница, поверх неё прозрачные поля ввода, повторяющие
поля PDF-формы. Блок «Магические предметы» разбит на 16 отдельных строк —
всего 76 полей.

## Установка

1. Откройте комнату Owlbear Rodeo.
2. **Settings → Extensions → Add Extension**.
3. Вставьте ссылку на манифест:

   ```
   https://mmescherin93.github.io/azag-sheet/manifest.json
   ```

4. Нажмите **Install**. Кнопка листа появится в левом верхнем углу комнаты.

Обновление — снять расширение и установить заново по той же ссылке.

## Что умеет

- Несколько персонажей: выпадающий список, «＋ Новый», «Удалить».
- Все поля бланка: имя, игрок, динамика группы, Умение, Выносливость, Удача,
  магические и обычные предметы, навыки (название / ранг / использование),
  оружие, броня, щит, черты характера, чекбоксы костей брони.
- Автосохранение в общие метаданные комнаты — листы видят все участники.
- У каждого участника **свой выбранный персонаж**: выбор хранится в
  `localStorage` клиента и не переключает лист у остальных.
- Масштаб `− / % / +` и вписывание листа по размеру окна.

## Данные

Состояние хранится в метаданных комнаты Owlbear Rodeo под ключом
`com.azag.sheet/state`:

```json
{ "currentId": "c_…", "chars": [{ "id": "c_…", "fields": { "chr name": "…" } }] }
```

Выбранный персонаж хранится отдельно, в `localStorage` клиента
(`azag-sheet-current-v1`), поэтому переключение листа не действует на других
участников.

В Owlbear Rodeo общая метадата комнаты ограничена **16 КБ**, поэтому в расширении
действуют разумные лимиты: до 12 персонажей, 1200 символов в многострочном поле
и 140 символов в строке. Если лимит превышен, лист остаётся в локальном
хранилище, а в статусе появляется предупреждение — сократите текст или удалите
персонажа.

Вне Owlbear Rodeo (при открытии `index.html` напрямую) лист работает на
`localStorage` браузера.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Разметка панели и листа |
| `styles.css` | Внешний вид и адаптация под ширину попапа |
| `app.js` | Поля, персонажи, сохранение, масштаб |
| `fields.generated.js` | Поля PDF-формы: координаты, тип, многострочность; «Магические предметы» — 16 строк |
| `sheet.png` | Страница PDF в 3×, фон листа |
| `icon.png` | Иконка расширения |
| `manifest.json` | Манифест Owlbear Rodeo |
| `docs/store.md` | Карточка для каталога расширений |

`fields.generated.js` сгенерирован из PDF и вручную не редактируется.

## Разработка

Открыть `index.html` в браузере или поднять статический сервер:

```powershell
npx serve .
```

Проверка синтаксиса:

```powershell
node --check app.js
node --check fields.generated.js
```

Исходная версия модуля для собственного VTT лежит в
[MMescherin93/vtt-2.0](https://github.com/MMescherin93/vtt-2.0/tree/main/desktop-host/extensions/azag-sheet).
